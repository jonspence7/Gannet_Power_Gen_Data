# Gannet_Power_Gen_Data

This project has been created to enable quick and easy review of data taken from the .CSV files which are produced by Siemens FT125 data logging software.

Normally, this is processed in Excel, but this is laborious and when trying to review multiple files can be very repititive.

The premise is using pandas to interpret the .csv file, then seaborn to distill the data and matplotlib to plot the data for review.

Ongoing revisions would change the fixed element of the series plotting to be changed to selectable variables.
